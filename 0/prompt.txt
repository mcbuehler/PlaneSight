Problem:
Cognitive overload 
Agent Prioritization
Most tools only offer a 1D list of agents we want a 2D plane for grouping and better understanding
Context Switching
Dependencies between agents / tasks
Understanding what agents did



Solution:
Added visual interface with Herder backend. Display a pixel art style minimalistic city.
Houses indicate tasks: One house per agent workflow
Color highlights indicating what’s happening underneath:
Red → Bugfix
Green → Planning
Blue → Implementing
Green → Testing
Purple → Security Review
…
The color pulsates when it’s processing and shines bright when it needs an input.
Size indicates criticality (or token usage, processing time)
Streets indicate dependencies
Not quite sure yet whether we should visualize them or not. Maybe it’s better to use streets to group related tasks, e.g., 3 agents working on the same thing, e.g., the UI.
Personalized prioritization
Each user decision is saved and is converted to a personalization for a decision agent (Jev).


Pitch

Imagine you are coming back from lunch and you see 8 agents requiring your attention.
Which one should you look into first? This is what Plane Sight is trying to help you decide.

Your product development is like an airport. Agents are taking off from the terminal, spin their engines and generate trails before they land again. To prevent any unnecessary delays, a short turnaround time is crucial.

Plane Sight acts as your air traffic controller. It hides agents which are in-flight, because they are not actionable. It recognizes the most urgent task in front of the line and identifies dependencies between agents, so they don’t collide.

In our control tower sits our operator is Gemini 3.8 Flash, which sees all of your agent sessions from above and lines them up in the right order of priority.

On the ground control we have Herdr, which takes command from our operators and leads the agents the right way.

The check-in process in Agent Airport International (AAI) is operated by Entire, so the high throughput is handled smoothly.

So, you’re coming back from lunch. 8 agents are ready for their next flight. Which one should you send off next? You need an air traffic controller to make a decision for you, and thanks to our tool, the answer is in plain sight.
